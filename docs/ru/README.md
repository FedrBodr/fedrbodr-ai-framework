## Только на английском

ADRs, integration notes, project templates, contribution rules, security policy и agent instructions остаются на английском. Это нормативные или исполняемые рабочие артефакты; единый язык снижает риск расхождения источников истины. Их можно переводить позднее при наличии процесса синхронизации и ответственных reviewers.
