# Security Policy

## Project status

FedrBodr AI Framework is currently a documentation-first project and does not execute application code. Security reports may still concern unsafe guidance, template behavior, repository configuration, or future executable components.

## Reporting a vulnerability

Do not report vulnerabilities or sensitive findings in a public issue.

Use GitHub private vulnerability reporting for this repository if it is available. Otherwise, contact a maintainer through the maintainer's GitHub profile and ask for a private reporting channel. Do not include exploit details or secrets in the initial public-facing message.

Include the affected document or component, potential impact, reproduction information where applicable, and a safe way to follow up. The maintainer will acknowledge the report and coordinate disclosure based on its severity and the project's capabilities.

## Sensitive data

Never commit API keys, access tokens, passwords, private keys, unredacted environment files, customer data, proprietary source material, private prompts, or sensitive personal data. Use secret-management systems outside this repository. Examples in documentation must use unmistakably fictitious values.
