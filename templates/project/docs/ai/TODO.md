# Short-Term TODO

This file tracks concrete, actionable work needed soon. The roadmap describes desired outcomes and direction; this TODO list identifies tasks that a named owner can complete and verify. Prefer the project's issue tracker when it is the established source of truth.

## Task format

- [ ] **Actionable task**
  - **Owner:** Person or team, or `Unassigned`.
  - **Status:** Ready | In progress | Blocked.
  - **Context:** Why this is needed and links to requirements or evidence.
  - **Specification:** Approved requirement or specification section, when applicable.
  - **Done when:** Observable acceptance criteria.
  - **Evidence:** Tests, review, or inspection that will demonstrate completion.

## Active tasks

Add only near-term tasks. Remove completed items after recording any durable outcome in the relevant document; Git retains the history.
